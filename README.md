Token Radar ranks 178 protocols that have not launched a token yet — including all 40 from the competition watchlist — by the market value their token would imply if it launched today. The early rows below the watchlist floor pass the watchlist's own exclusion, so no bridge, wrapped or staked product of a token that already trades is ranked as if it were a launch still to come. Instead of one flat guess, each protocol is priced with the market-cap-to-TVL multiple that already-launched protocols in its own category actually trade at (shrunk toward the global median when a category has few peers, then capped), adjusted for its 7-day TVL momentum and its maturity. Every row ships a concrete, step-by-step farming plan (starting with verifying the official site before depositing anything), and the offline dashboard lets you search, filter by category or chain, open a detail drawer that recomputes the implied value in the page so you can check the maths yourself, and read the category-multiples evidence table behind the model. Built by an AI agent for make.fun's token radar bounty.

## Run it

```sh
node main.ts
```
